# Linux Command Line Practical Task

A GitHub-ready workflow for completing the **Linux Command Line Practical Task** in Kali Linux.

## Objective

Demonstrate understanding of basic Linux commands by completing the supplied practical task as the newly created `student01` user.

## Lab Scope

The workflow follows the task in its original order:

1. Create and switch to `student01`.
2. Create the `project` directory structure and required files.
3. Edit, copy, move, and rename files.
4. Apply the required `chmod` permissions.
5. Remove `admin_notes.txt`, create `backup`, and copy the contents of `docs` and `scripts` into it.
6. Perform the required final checks.
7. Optionally save command history.

## How to Use

1. Open Kali Linux.
2. Follow `commands/COMMANDS.md` in order.
3. Perform the commands manually in the terminal.
4. Use the evidence checklist to capture the required proof.
5. Store screenshots only in `screenshots/`.
6. Complete the final `tree project` and `ls -la` checks.
7. If the optional history task is completed, keep `commands_used.txt` in the student's home directory as required by the lab.

## Important

This repository is a **workflow/template**, not a claim that the lab has already been completed. Evidence placeholders are intentionally empty until the commands are actually performed.

The workflow does not add extra lab requirements beyond the supplied task.
