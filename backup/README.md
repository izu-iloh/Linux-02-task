# Backup

This directory documents the location used by the lab for the final backup operation.

During the lab, `backup` must be created inside `~/project/` and the entire contents of `docs` and `scripts` must be copied into it.

The completed backup is therefore expected to contain:

```text
project/backup/
├── docs/
└── scripts/
```

The actual backup should be generated by completing the lab commands rather than pre-populated in this template.
