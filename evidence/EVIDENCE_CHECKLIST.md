Use this checklist while completing the task.

- [ ] `whoami` confirms `student01`.
- [ ] `project/` exists with `docs/`, `scripts/`, and `bin/`.
- [ ] `docs/report.txt` contains the required initial line and the line added with nano.
- [ ] Hidden-file viewing was performed with `ls -la`.
- [ ] `.secret.txt` was created with the required text before being moved.
- [ ] `report.txt` was copied to `scripts/`.
- [ ] `.secret.txt` was moved to `bin/` and renamed `classified.txt`.
- [ ] `scripts/install.sh` contains the required two lines.
- [ ] `install.sh` is executable by all users.
- [ ] `classified.txt` has no read permission for others.
- [ ] `admin_notes.txt` was created with owner read/write-only permissions and then deleted.
- [ ] `backup/` was created inside `project/`.
- [ ] The contents of `docs` and `scripts` were copied into `backup`.
- [ ] `tree project` was run.
- [ ] `ls -la` was used for the final permission/location checks.
- [ ] Optional: `commands_used.txt` was created in the home directory from `history`.
